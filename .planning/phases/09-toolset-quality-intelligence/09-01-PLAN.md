# 09-01 Plan: Derived Capability Flags and Quality Summaries

## Goal

Expose compact, derived quality intelligence for registered toolsets so agents can prefer
better-described and more composable servers without activating every downstream MCP.

## Requirements

- `QUAL-01`: Registered summaries expose derived capability flags.
- `QUAL-02`: Toolbox exposes compact quality summaries and remediation hints.
- `QUAL-05`: Future protocol-shaped fields are represented as inert metadata only.

## Proposed Model Additions

Add compact models in `toolbox/models.py`:

- `ToolsetCapabilityFlags`
- `ToolsetQualitySummary`
- `ToolsetFutureCapabilities`

Candidate flags:

- `has_cached_contract`
- `has_mounted_contract`
- `has_guidance`
- `has_recipes`
- `has_examples`
- `supports_health_check`
- `supports_batch_composition`
- `supports_program_composition`
- `supports_structured_outputs`
- `requires_auth`
- `requires_workspace_root`
- `has_future_task_metadata`
- `has_future_trigger_metadata`
- `has_future_streaming_metadata`
- `has_future_reference_metadata`

Candidate quality fields:

- `score`: integer 0-100
- `grade`: `excellent`, `good`, `thin`, or `risky`
- `strengths`: compact strings
- `gaps`: compact strings
- `recommended_next_action`: one of `use`, `inspect`, `refresh`, `add_metadata`, or `avoid_until_fixed`

## Implementation Steps

1. Write failing tests in `tests/test_service.py` for a fully described toolset, a thin
   toolset, a stale toolset, and a cached-contract toolset.
2. Add the model classes and optional future metadata fields to `ToolsetRecord`.
3. Implement service helpers that derive capability flags from registration metadata,
   cached schema snapshots, mounted runtimes, health state, and contract summaries.
4. Add a public `inspect_toolset_quality(namespaces)` service method.
5. Include the compact quality summary in `toolbox_brief`, `get_toolset_guide`,
   `audit_toolbox_catalog`, and possibly `list_toolsets` only if the payload stays small.
6. Expose the quality inspection tool through `toolbox/server.py`.
7. Update README and planning summaries.

## Validation

- Focused service tests for quality scoring and flags.
- MCP server exposure test for the new quality inspection tool.
- Secret regression probe: quality output must not reveal transport args/env values.
- Full verification before commit:
  - `python -m pytest -q`
  - `python -m compileall toolbox tests`
  - `python -m pytest -q -W error::pytest.PytestUnraisableExceptionWarning`

## Commit Boundary

Commit as `Add toolset quality summaries` after tests and docs pass.
