# 09-02 Plan: Lazy Guidance Sources and Composition Examples

## Goal

Let registered toolsets expose richer usage guidance and composition examples lazily,
without merging long guidance bodies or example programs into the default discovery
surface.

## Requirements

- `QUAL-03`: Toolset registrations can point to lazy guidance sources.
- `QUAL-04`: Toolset registrations can expose composition examples that are listed
  compactly and loaded explicitly by id.

## Proposed Model Additions

Add compact metadata in `toolbox/models.py`:

- `ToolsetGuidanceSource`
- `ToolsetCompositionExample`
- `ToolsetExampleSummary`
- `ToolsetExampleDetail`

Candidate guidance source fields:

- `kind`: `inline`, `file`, or `registered`
- `title`
- `summary`
- `path`
- `content`

Candidate example fields:

- `id`
- `title`
- `summary`
- `kind`: `batch` or `program`
- `tags`
- `required_namespaces`
- `payload`

## Implementation Steps

1. Write failing tests in `tests/test_service.py` for registering guidance metadata and
   composition examples without loading their full bodies in search/list/overview.
2. Add model fields to `ToolsetRecord`, keeping defaults empty for old state files.
3. Implement path validation for file-backed guidance sources:
   - Resolve paths relative to the registered transport `cwd` when present.
   - Reject paths outside that root.
   - Reject `.toolbox/state.json`, `.toolbox/state.key`, and obvious generated secret/state files.
4. Implement service methods:
   - `list_toolset_examples(namespace)`
   - `load_toolset_example(namespace, example_id)`
   - `load_toolset_guidance(namespace)`
5. Keep list methods summary-only and make detail loaders explicit.
6. Expose the new methods through `toolbox/server.py`.
7. Update `get_toolset_guide` so it advertises guidance availability and example ids
   without embedding long bodies.
8. Update README, `MCP_SERVER_RECOMMENDATIONS.md`, and phase summaries.

## Validation

- Focused service tests for lazy guidance and example loading.
- Path-boundary tests for guidance file loading on Windows paths.
- MCP server exposure tests for the new lazy loaders.
- Secret regression probe: guidance loaders must not read protected Toolbox state or
  transport secret files.
- Full verification before commit:
  - `python -m pytest -q`
  - `python -m compileall toolbox tests`
  - `python -m pytest -q -W error::pytest.PytestUnraisableExceptionWarning`

## Commit Boundary

Commit as `Add lazy toolset guidance examples` after tests and docs pass.
