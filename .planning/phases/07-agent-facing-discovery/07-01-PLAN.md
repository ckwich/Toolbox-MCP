# 07-01 Plan: Overview, Metadata, and Suggestions

## Goal

Make Toolbox self-describing for agents while preserving progressive discovery and a
small always-on surface.

## Requirements

- `AGENT-01`: Toolbox exposes a compact overview of registered capability categories.
- `AGENT-02`: Toolset registrations support agent-facing metadata fields.
- `AGENT-03`: Search and task suggestions use the metadata fields.
- `AGENT-04`: Discovery helpers remain metadata-first and do not activate toolsets.

## Steps

1. Extend `ToolsetRecord` with agent-facing metadata defaults: category, aliases,
   examples, activation hint, cost hint, latency hint, and trust level.
2. Add service helpers for `toolbox_overview` and `suggest_toolsets_for_task`.
3. Include the metadata in `search_toolsets`, `list_toolsets`, `get_toolset_status`,
   and `register_toolset`.
4. Expose the new helpers through the MCP server.
5. Add regression tests for service-level and MCP-level behavior, including a
   skill-loader-style registration that is discoverable by intent.
6. Update README and planning closeout.

## Verification

- `python -m pytest -q tests/test_service.py -k "toolbox_overview or suggest_toolsets or agent_metadata"`
- `python -m pytest -q`
- `python -m compileall toolbox tests`
