# 08-01 Plan: Passive Agent Guidance Affordances

## Goal

Add the remaining agent-facing guidance layer so a fresh session can discover, plan, and
use Toolbox intentionally without relying on prior chat context.

## Requirements

- `GUIDE-01`: Add a compact Toolbox brief with recommended flow, active toolsets,
  task-specific suggestions, and next actions.
- `GUIDE-02`: Add a dry-run activation plan for a task and scope.
- `GUIDE-03`: Add compact toolset recipes and a lazy per-toolset guide.
- `GUIDE-04`: Add catalog linting for missing metadata that weakens agent discovery.

## Steps

1. Add failing service and MCP-level regression tests for brief, activation planning,
   guides, recipes, and catalog audit behavior.
2. Extend the shared models with recipe metadata and guidance result envelopes.
3. Implement service-level guidance helpers without auto-activation or raw schema exposure.
4. Expose the guidance helpers through the FastMCP server.
5. Update README, planning state, handoff, and recommendation notes.
6. Run focused tests, full tests, compile verification, and the strict warning lane.

- `python -m pytest -q tests/test_service.py -k "agent_guidance_surfaces or agent_facing_overview"`
- `python -m pytest -q`
- `python -m compileall toolbox tests`
